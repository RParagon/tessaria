# Idiomas

O jogo é escrito em português (pt-BR). Os outros idiomas ficam em dicionários, como o `src/i18n/en.json`, cuja chave é
o **texto em português**, com os números trocados por `{n}`.

## Como funciona
- `src/i18n/index.ts` escolhe o idioma: o que o jogador escolheu (menu ou título, guardado no aparelho) ou, na primeira
  vez, o idioma do navegador (português para quem usa pt, inglês para o resto).
- A **tradução acontece na tela**: um observador troca os textos (e `title`, `placeholder`, `aria-label`, `data-tip`)
  assim que aparecem. O código do jogo continua escrevendo em português; o que não tiver tradução continua em português.
- Ficam de fora: o que o jogador escreve (chat, nomes), elementos com `data-noi18n` e campos de texto.
- As falas dos moradores são traduzidas inteiras antes de "digitar" (`nextLine` em `content/story.js`).
- No build de teste o padrão é português (os testes conferem textos em português); um teste escolhe o inglês de propósito.

## Para traduzir textos novos
1. `npm run i18n:extract`: lê o código e diz quantos textos ainda não têm tradução (`--out arquivo.json` salva a lista).
2. `npm run i18n:harvest`: abre o jogo em inglês, passa pelos menus e regiões e lista o que apareceu sem tradução
   (pega as frases montadas aos pedaços, que a leitura do código não vê).
3. Acrescente os pares em `src/i18n/en.json` mantendo os `{n}`, as maiúsculas e os símbolos. Glossário (Centelhas →
   Sparks, Fenda → Rift, Tecelão → Weaver…) no histórico da 0.59 em `CHANGELOG.md`.

## Limites conhecidos (0.59)
- Nomes de itens gerados (ex.: "Espada Sussurrante") e algumas frases com nomes no meio ainda aparecem em português.
- As páginas de Termos e Privacidade são só em português.
